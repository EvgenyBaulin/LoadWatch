# LoadWatch — фронтенд

Одностраничное приложение на Vue 3 + Vite + TypeScript: дашборд в духе инженерных панелей мониторинга, тёмная и светлая темы, интерфейс на русском и английском.

## Требования

- Node.js 20.19+ (проверено на 24.x), npm 10+.
- Бэкенд LoadWatch API: в разработке по адресу `http://127.0.0.1:8000`. Другой адрес задаётся переменной `LOADWATCH_API_URL`, например `LOADWATCH_API_URL=http://10.0.0.5:8000 npm run dev`.

## Скрипты

| Команда | Что делает |
|---|---|
| `npm ci` | установка зависимостей строго по `package-lock.json` (версии зафиксированы точно) |
| `npm run dev` | dev-сервер Vite, `/api` проксируется на бэкенд |
| `npm run build` | проверка типов (`vue-tsc --noEmit`) и production-сборка в `dist/` |
| `npm run preview` | локальный просмотр собранного `dist/` (с тем же прокси `/api`) |
| `npm run lint` | ESLint (flat config: `typescript-eslint`, `eslint-plugin-vue`) |
| `npm run type-check` | только проверка типов, strict |
| `npm run i18n:check` | падает, если наборы ключей `ru.json` и `en.json` различаются или код использует отсутствующий ключ |

В production `dist/` отдаёт Nginx с того же origin, что и API (`/api/v1`), поэтому CORS не нужен. Для SPA все неизвестные пути отдают `index.html` (`try_files $uri /index.html`).

## Структура

```
src/
  api/          client.ts (fetch, Bearer-токен, ApiError с кодом, скачивание файлов),
                endpoints.ts (функции по эндпоинтам), types.ts (типы ответов по OpenAPI)
  stores/       auth (токен, профиль), preferences (тема и язык), toasts
  i18n/         настройка vue-i18n, русские правила множественного числа, таблицы «значение → ключ»
  locales/      ru.json, en.json — все строки интерфейса
  charts/       регистрация Chart.js, плагин меток на графиках, палитра из CSS-переменных
  composables/  форматирование (Intl), перевод ошибок, загрузка данных, временной диапазон
  components/   Panel, StatPanel, MetricChart, DataTable, Skeleton, EmptyState, ErrorMessage,
                TopBar, SideNav, ThemeSwitcher, LanguageSwitcher, TimeRangePicker и др.;
                site/ — панели карточки сайта; editor/ — конструктор шагов и результат dry-run
  views/        страницы: вход, регистрация, сайты, карточка сайта, дашборд, история запусков,
                запуск, редактор сценария, каналы и настройки
  styles/       tokens.css (дизайн-токены обеих тем), base.css (общие классы)
  utils/        модель формы сценария и преобразование в формат API
scripts/i18n-check.mjs   проверка локалей
```

## Принятые решения

- **Хранение токена — `localStorage`.** Проще всего для SPA на одном origin с API: токен переживает перезагрузку, запросы отправляются с заголовком `Authorization: Bearer`. Компромисс: токен доступен любому JS на странице, поэтому XSS особенно опасен. Защита: нет `v-html` (правило ESLint `vue/no-v-html: error`), все данные выводятся экранированными, внешних скриптов нет, срок жизни токена ограничен сервером (`expires_in`), по ответу 401 приложение выходит и ведёт на `/login`. Альтернатива — httpOnly-cookie — потребовала бы CSRF-защиты на бэкенде.
- **Скачивание CSV и PDF** идёт через `fetch` с заголовком авторизации → `Blob` → временная ссылка, чтобы не передавать токен в URL.
- **Метки на графиках** (деплои, комментарии, регрессии) рисует собственный небольшой плагин Chart.js (`src/charts/annotations.ts`) — отдельная зависимость не нужна. Подписи меток дублируются списком под графиками.
- **Тема.** Токены в `tokens.css` для `[data-theme="dark"]` и `[data-theme="light"]`; компоненты используют только переменные. Режим (светлая / тёмная / системная) хранится в `localStorage` (`lw.theme`) и применяется инлайн-скриптом в `index.html` до загрузки Vue — без вспышки. Системный режим следит за `prefers-color-scheme` на лету. Графики читают цвета из CSS-переменных и перекрашиваются при смене темы без перезагрузки.
- **Язык.** По умолчанию — из `navigator.language` (не `ru` → `en`). Явный выбор хранится в `localStorage` (`lw.locale`) и важнее профиля. После входа: если язык в браузере не выбирали, берётся `users.locale`; если выбирали и он отличается, он отправляется на сервер (на этом языке приходят уведомления). Смена языка мгновенно меняет `<html lang>` и заголовок вкладки.
- **CSP.** Если на сервере включена Content-Security-Policy, инлайн-скрипт темы разрешается хэшем: `script-src 'self' 'sha256-qYmUCOwIbxnSlsYu+s7lrsNZHLGNeTrakUFVGQAAXqw='` (хэш меняется при любой правке этого скрипта).
- **Ошибки API** переводятся по стабильному `error.code`; для неизвестных кодов — общий текст. Ошибки валидации (422) показываются рядом с полями по `details[].loc`, текст выбирается по `details[].type`.
- **История запусков:** фильтры и страницы — на сервере, сортировка по колонкам — внутри текущей страницы (API не поддерживает сортировку).
- **Временной диапазон и автообновление дашборда** хранятся в query-параметрах (`range`, `from`, `to`, `refresh`), ссылкой можно поделиться. Фоновая вкладка не обновляется.
- **Сборка:** Chart.js и date-fns вынесены в отдельный чанк `charts`, страницы входа и списков его не загружают.
